# Security Policy

## Supported versions

Security fixes are provided for the latest published minor release. Users
should upgrade to the latest available version before reporting an issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include secrets,
credentials, or production cache data in a report.

Use [GitHub private vulnerability reporting](https://github.com/fedikhaled/SmartCacheDB/security/advisories/new).
If private reporting is unavailable, email `fedikhaled01@gmail.com` with the
subject `SmartCacheDB security report`.

Include the affected version, backend configuration, impact, reproduction
steps, and any known mitigation. You should receive an acknowledgment within
five business days. Details will be coordinated privately until a fix and
release are available.
